## Hi, I'm Jason

I build web applications with Python and TypeScript, from Django REST APIs to responsive Next.js interfaces. My projects explore marketplaces, authentication, role-based access, and the workflows that connect users with products and communities.

I care about clear APIs, maintainable code, and documentation that makes a project easier to run and understand.

## Featured projects

### [Neighbourhood Market](https://github.com/JasonPretorius559/django-marketplace)
A Django eCommerce application with separate buyer and vendor workflows.

- Store and product management with ownership-based permissions.
- Shopping carts, checkout, order history, and invoice emails.
- Verified purchase reviews and expiring, single-use password reset links.
- REST API, setup documentation, and automated tests.

**Built with:** Python · Django · Django REST Framework · MariaDB

### [TinkerTown](https://github.com/JasonPretorius559/TTKTown)
A social marketplace for collectible figurines, bringing collection tools and community features into one application.

- Catalogue browsing, collections, wishlists, and marketplace listings.
- Profiles, a social feed, messaging, and notifications.
- Firebase authentication and access rules for roles and ownership.
- Responsive interfaces built with strict TypeScript.

**Built with:** TypeScript · Next.js · React · Firebase · Vercel Blob

> TinkerTown is in development. Its README documents the remaining production integrations and deployment requirements.
